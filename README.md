# Aryan Vishwakarma — Graphic Designer Portfolio

A modern, high-performance portfolio featuring a 60/120fps smooth scroll-driven 3D video sequence animation, glassmorphism UI components, dynamic skill sliders, an interactive experience timeline, testimonials, and responsive navigation.

## ✨ Features

- **Smooth Scroll-Driven Frame Animation**: 240 video frames interpolated smoothly using a linear damping engine (LERP) on a high-DPI canvas.
- **Hero Section**: Bold typography, action buttons, social links, and fullscreen view.
- **About Section**: Professional bio, direct email, and location card.
- **Resume & Skills**: Interactive Adobe CC sliders, language proficiency meters, personal skills, and experience timeline.
- **Testimonials Section**: Glassmorphic client endorsement cards with 5-star ratings.
- **Modern Footer**: Brand summary, quick links, and smooth back-to-top button.
- **Zero Heavy Frameworks**: Built with pure HTML5, vanilla CSS3, and modern JavaScript.

## 🚀 Getting Started

### Local Setup
Simply open `index.html` in any modern web browser, or run a local static server:

```powershell
powershell -ExecutionPolicy Bypass -File server.ps1
```
Then visit: `http://localhost:8080`

## 🛠️ Built With

- **HTML5 & CSS3** (Vanilla Glassmorphism Design System)
- **JavaScript (ES6+)** (Canvas Rendering, Progressive Preloading & LERP Engine)
- **Google Fonts** (Outfit & Space Grotesk)
